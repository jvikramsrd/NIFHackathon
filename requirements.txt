#
# INSTALL ORDER (important on Windows):
#
#   Step 1 — PyTorch with CUDA 12.1 (for RTX A4000):
#     pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
#
#   Step 2 — Geospatial stack:
#
#     RECOMMENDED — pip (works on Windows, Linux, macOS):
#       pip install rasterio fiona geopandas
#
#     ALTERNATIVE — conda (gives libgdal-ecw native ECW driver, no QGIS needed):
#       conda install -c conda-forge libgdal-ecw rasterio fiona geopandas
#
#   Step 3 — ECW support (skip if using conda libgdal-ecw above):
#
#     Windows → Install QGIS (free):  https://qgis.org/download
#       The pipeline calls utils/ecw_compat.ensure_ecw_driver() at startup
#       which auto-detects QGIS and loads its ECW DLLs via ctypes so that
#       rasterio.open() works on .ecw files directly — no temp file conversion,
#       no disk overhead.  All shapefile burning, strip-reads, and tiling
#       work identically on ECW as on GeoTIFF.
#
#     Linux / macOS → conda:
#       conda install -c conda-forge libgdal-ecw
#       (QGIS runtime injection is Windows-only; Linux uses the native driver)
#
#   Step 4 — Everything else:
#     pip install -r requirements.txt
#
#   Step 5 — Optional CRF (requires VS Build Tools 2022 on Windows):
#     pip install pydensecrf2
#
# ══════════════════════════════════════════════════════════════════════════════
